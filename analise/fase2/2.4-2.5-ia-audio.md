## 2.4.1 `deepagents_capi.dll` — API C do agente de IA

**Natureza:** DLL Go `c-shared` de 42 MB (`_cgo_dummy_export`, trampolines de SQLite). SDK interno `code.byted.org/cc-family-infra/carrier-agent-sdk/{deepagents,capi}` construído sobre **CloudWeGo Eino** (`eino/compose` 2.043 refs, `eino/schema` 3.722, `eino/components` 2.230, `eino/adk`) e `eino-ext` com os adaptadores de modelo **`model/ark`** (Volcengine Ark: `chat_completion_api`, `responses_api`), **`model/openai`** e **`model/gemini`** [evidência: `strings/deepagents_capi.dll.all.txt`].

### Arquitetura de carregamento (quem chama a DLL)

Ninguém importa `deepagents_capi.dll` estaticamente. Ela é carregada em runtime por um **loader** C++ embutido no `VECreator.dll` e no `DeepAgentsService.dll`:

```
VECreator.dll (UI Qt, processo "browser")
  └─ agent::LocalAgentChannel::initializeDeepAgentsShell
       └─ ServiceRemote<deepagents_service::mojom::DeepAgentService>
            ├─ CreateServiceInMainProcess     (mesmo processo)
            └─ CreateServiceInServiceProcess  (processo filho de serviço)
                 └─ DeepAgentsService.dll  (export único: entryPoint; importa bd_mojo, sscronet, videoeditor)
                      └─ "deepagents_loader_skeleton_v1"
                           da_loader_configure(dylib_path) → LoadLibrary("/deepagents_capi.dll")
                           da_get_abi_version / da_get_version
                           da_get_api_table(abi)  → struct da_core_api_s (tabela de ponteiros)
                           replay de da_set_log_callback / da_set_log_min_level / da_set_crash_callbacks
```

Evidências: `DeepAgentsService.dll` → `"/deepagents_capi.dll"`, `"da_loader_configure must be called before the real dylib is loaded"`, `"da_get_api_table returned NULL for requested ABI version"`, `"failed to replay da_set_log_callback"`; `VECreator.dll` → `"deepagents_loader_skeleton_v1"`, `"[agent][core]LocalAgentChannel deepagents shell service created"`, `C:\90741\CapCutPC\Capability\DeepAgentsShell\{deepagent_browser_bridge, child\deepagent_child_session_bridge, child\deepagent_child_capi_thunks, deepagent_mojom_converters, local_agent_tool_result_projector}.cpp`.
